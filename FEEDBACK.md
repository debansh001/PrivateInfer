## Changes Implemented Based on Beta Feedback

The following changes were shipped directly in response to tester feedback. Each item references the git commit(s) where the fix was applied.

---

### ✅ Copy Button for AI Result Output
**Requested by:** Manash Koley  
**Commit:** [`e3a4a9c`](https://github.com/debansh001/PrivateInfer/commit/e3a4a9c)  
Added a one-click **Copy** button next to the decrypted AI result on the Query Status page (`/query/[id]`). No more drag-to-highlight on mobile.

---

### ✅ Processing State — Spinner + Queue Message
**Requested by:** Rubina Mondal  
**Commit:** [`e3a4a9c`](https://github.com/debansh001/PrivateInfer/commit/e3a4a9c)  
The query submission page now shows an animated spinner (`animate-spin`) and the message **"Waiting for ZK proof… (Please do not refresh)"** while the transaction is being processed on-chain. Previously the page appeared frozen during proof generation.

---

### ✅ Explorer Hint Box — Red Warning Banner
**Requested by:** Faisal Islam  
**Commit:** [`e3a4a9c`](https://github.com/debansh001/PrivateInfer/commit/e3a4a9c)  
The 1AM explorer hint box was redesigned as a bold red **🚨 ATTENTION** warning banner so users immediately notice it before submitting a query.

---

### ✅ Theme Toggle Fixed (Light / Dark)
**Requested by:** Habibullah Mir  
**Commit:** [`94c8b69`](https://github.com/debansh001/PrivateInfer/commit/94c8b694a58cc98297fcdae101683ded63dbdfa4)  
The light/dark theme toggle was previously broken — both themes shared the same dark color palette. The CSS was split into proper `:root` (light) and `html.dark` (dark) blocks with distinct palettes so the toggle visually switches correctly. Also fixed Tailwind v4 `@custom-variant dark` selector to match `next-themes`' class application on `<html>`.

---

### ✅ Wallet Connect Button — Real Functionality
**Requested by:** Multiple testers (general UX)  
**Commit:** [`54acd1b`](https://github.com/debansh001/PrivateInfer/commit/54acd1b106a5880645914c3de9d39fefcf0540b8)  
The "Connect Wallet" button in the header was previously just a link to `/query/new`. It is now a real connect button that:
- Calls `connect()` from `WalletContext`
- Shows a loading spinner while connecting
- Displays the connected wallet address with a green live-pulse dot
- Includes a disconnect button
- Shows "No Wallet Found" if no 1AM extension is detected

---

### ✅ Lace Wallet — Network Mismatch Notification
**Reported by:** Priya Das *(Lace Wallet)*  
**Commit:** [`54acd1b`](https://github.com/debansh001/PrivateInfer/commit/54acd1b106a5880645914c3de9d39fefcf0540b8)  
When a non-1AM wallet or wrong network is detected on connect, a toast notification now informs the user: *"PrivateInfer supports 1AM Wallet on Midnight PREPROD only."* The underlying issue (network mismatch: preprod vs preview) is a Lace Wallet configuration problem — Lace must be set to PREPROD network before connecting.

---

### ✅ Query History Page (`/history`)
**Requested by:** Fatima Khatun  
**Commit:** [`659cc93`](https://github.com/debansh001/PrivateInfer/commit/659cc93)  
**Status:** ✅ **Shipped**

A dedicated `/history` page now shows all past queries for the connected wallet address. Features:
- Fetches queries live from `/api/queries?wallet=<address>` — no mock data, all real DB records
- Shows status badge (Processing / Result Ready / Paid / Failed) with colour coding and icons
- Time-ago timestamps (e.g. "3h ago")
- AI result preview inline for completed queries
- Per-query **View on 1AM Explorer** link and **View Status** button
- Refresh button + summary stats (Total / Completed / Pending)
- Graceful empty, loading, error, and not-connected states
- Added **History** link to the main site navigation header
